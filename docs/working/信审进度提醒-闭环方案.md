## 1. 一句话结论

> 信审进度提醒 = **HSM 推客户（入口）+ 销售侧升级（兜底）+ 客户回复触发 24h 窗口（接续）+ 线索详情时间线（可视化）**
>
> 单靠 HSM 推客户 = "通知黑洞"（客户已读未回 / 已读已回但销售不知道）。
> 必须配套**销售侧任务卡 + 时间线 + 二次提醒 + 升级**三件套。

## 3. 4 个动作（执行清单）

### 动作 1 · HSM 模板（已落地到 `跟进策略-Skill-PC.html` `hsmData` 数组）

| 模板 ID | 类别 | 触发节点 | 触发条件 | 西语正文要点 |
|--------|------|----------|---------|--------------|
| `hsm_precheck_result_approved_v1` | UTILITY | sop_08 / ms_8 / h5 | `review.result = approved` | "Hola {{1}}, ¡buenas noticias! Tu evaluación con {{2}} para el {{3}} fue aprobada…" |
| `hsm_precheck_result_rejected_v1` | UTILITY | sop_08 / ms_8 / h5 | `review.result = rejected AND alternative_path = true` | "Hola {{1}}, sobre el {{2}}: la evaluación inicial no fue aprobada. Podemos explorar alternativas…" |
| `hsm_precheck_result_more_info_v1` | UTILITY | sop_08 / ms_8 / h5 | `documents.pending IS NOT NULL` | "Hola {{1}}, para avanzar con tu evaluación necesitamos: {{2}}…" |
| `hsm_precheck_result_remind_v1` | UTILITY | sop_08 出口 | 客户 HSM 已读但 24h 未回复 | "Hola {{1}}, ¿pudiste ver el mensaje sobre el resultado de tu evaluación {{2}}?" |

**约束**：
- 全部使用 **UTILITY** 类别（避免 `MARKETING` 限流）
- 变量用 `{{1}}{{2}}` 数字占位（对齐 Meta 规范）
- **不使用**敏感词（"利率"、"零首付"、"100% 通过"、"固定库存"、"固定交付日期"、"一定能过"）

### 动作 3 · 线索详情页时间线（已落地到 `线索详情-PC.html`）

**位置**：`#precheck-timeline` 锚点（与工作台任务卡跳转对齐）

**视觉规范**（沿用 `工作台-今日任务模块.md` 设计原则）：
- 🔵 蓝 `--primary` = 进行中（pending / in_progress / submitted / MStar 审核中）
- 🟢 绿 `--success` = 通过（approved / 客户回复）
- 🔴 红 `--danger` = 拒绝（rejected）
- 🟡 黄 `--warning` = 补件 / 已读未回提醒（more_info / 已读未回 / 二次提醒排队）

**节点结构**（每个节点 = 时间戳 + 状态徽章 + 标签）：
```

[蓝] 09-07 15:30  in_progress 客户打开填写
[蓝] 09-07 16:00  submitted   客户提交预审
[蓝] 09-07 16:00  MStar 审核中 金融团队评估中
[绿] 09-07 18:45  approved    MStar 审核通过
[黄] 09-07 20:50  已读未回    二次提醒已排队
```

### 动作 4 · 客户视角演示页（已新建 `收件箱-客户已收到信审结果-PC.html`）

**3 种结果态切换**（URL hash）：
- `#approved` — 信审通过（演示客户主动回复 → 24h 窗口打开 → AI 接管自由对话）
- `#rejected` — 信审未通过（演示备选方案话术 + 已读未回二次提醒排队）
- `#more_info` — 补件（演示敏感资料走 MStar 受控金融流程，不在 WhatsApp 索要原图）

**右侧客户档案**：
- 客户信息（姓名 / RFC / 电话 / 邮箱 / 地区）
- 购车意向（车型 / 首付 / 月供目标 / 购车时间）
- 信审进度（复用左侧时间线视觉，缩微版）
- 预审字段 8/8 全部完成（RFC / 月收入 / 姓名 / 性别 / 电话 / 邮箱 / 地址 / 邮编）
- 当前跟进节点（sop_08）+ 负责人 + 下一动作 + 动作时间

**底部 24h 窗口状态条**：
- 已开（绿点 + 脉冲动画）：客户已回复 · AI 对话引擎已接管
- 未开（黄点）：HSM 已读未回 · 二次提醒已排队

## 4. 完整闭环时序图

```
MStar API review.result 变更
    │ Webhook
    ▼
任务编排引擎
    │
    ├── T0 ────────────────────────────────────────────────────
    │   │
    │   ├──→ HSM 推客户（3 套模板按结果触发）
    │   │     • approved   → hsm_precheck_result_approved_v1
    │   │     • rejected   → hsm_precheck_result_rejected_v1 (alternative_path=true)
    │   │     • more_info  → hsm_precheck_result_more_info_v1
    │   │
    │   ├──→ 销售工作台今日任务 +1 行
    │   │     • P0 + 状态 = "待二次提醒"
    │   │     • 30 分钟内未认领 → 自动 toast
    │   │
    │   └──→ 线索详情时间线 +1 节点
    │         • 时间戳 = 系统时间
    │         • 颜色 = 状态徽章
    │
    ├── T+24h（客户 HSM 已读但未回）───────────────────────
    │   │
    │   ├──→ 触发第 2 套 HSM（hsm_precheck_result_remind_v1）
    │   │     • 委婉问 "¿pudiste ver el mensaje…?"
    │   │
    │   └──→ 时间线追加黄色 "已读未回 · 二次提醒已排队" 节点
    │
    ├── T+48h（仍未回）─────────────────────────────────────
    │   │
    │   └──→ 销售侧升级
    │         • 工作台任务状态 → P0 · 即将超时
    │         • 通知销售主管（如果启用 SLA 升级）
    │         • 时间线追加灰色 "升级销售" 节点
    │
    └── 客户回复（任意时刻）───────────────────────────────
        │
        ├──→ 24h 窗口立即打开
        │     • AI 对话引擎可自由发送文本/图片/PDF
        │     • 工作台任务状态 → "已接管" 或 "AI 接管中"
        │
        └──→ 时间线追加绿色 "客户回复" 节点
              后续按 sop_08 → sop_09 推进
```
