# WhatsApp AI Agent 用户跟进规则

在 WhatsApp（Meta 平台）的规则下，“主动发消息”不能像普通手机号那样无限制地群发自由文本，而是必须遵守 Meta 的官方规则。

### 一、 主动发消息的 2 种场景与规则

#### 场景 A：24 小时服务窗口内（自由主动跟进）

- **规则**：只要潜在客户在过去的 24 小时内向你的 WhatsApp 发送过任何一条消息，这个 **“24小时窗口”** 就会打开。

- **Agent 的能力**：在此窗口内，AI Agent 可以**无限次、主动地**给客户发送任何自定义格式的文本、图片、车贷试算 PDF 文件或语音。

- **常见用途**：

- **延时追问（Follow\-up）**：当客户问完价格后突然沉默，Agent 可以在 2 小时或 6 小时后主动发消息：“*Hola, ¿pudiste revisar la cotización que te envié?*”（你好，查看刚刚给您的报价了吗？）

- **定时提醒**：在沟通中约定好时间，定时主动推送到期提醒。

#### 场景 B：超过24小时/完全未联系过的全新客户（模版消息唤醒）

- **规则：**如果距离客户上次发消息已经超过 24 小时，或者你要向导入的潜在客户名单主动发起第一次沟通，**不能直接发送自由文本**，必须使用经过 Meta 提前审核通过的**消息模版（Message Template / HSM）**。

- **Agent 的能力：**AI 无法从零生成这句话的结构，但 AI Agent 可以**触发**带动态变量的模版消息发送给客户。

- **示例模版**：

> - “*Hola \{\{1\}\}, vimos que estás interesado en el \{\{2\}\}\. Tenemos una promoción especial de enganche este mes\. ¿Te gustaría calcular tu mensualidad?*”
> 
> - （*\{\{1\}\} 为客户姓名变量，\{\{2\}\} 为意向车型变量*）
> 
> 

- **重启窗口**：一旦客户回复了这条模版消息，24 小时自由对话窗口再次被打开，AI Agent 就可以重新接管并进行自由对话了。

### 二、 针对墨西哥车贷业务的主动跟进（SOP）示例

AI Agent 可以实现以下主动跟进流程：

```Plain Text
[场景 1: 客户填写了网页/Facebook表单]
       │
       ▼
[AI Agent 自动主动发起 WhatsApp 沟通] 
(通过 Meta 审核的模版消息: "Hola Juan, recibimos tu solicitud para el Nissan Versa...")
       │
       ▼
[客户在 WhatsApp 中回复："Sí, me interesa"] (打开 24 小时窗口)
       │
       ▼
[AI Agent 实时自由互动] (询问首付、预算、索要银行流水等)
       │
       ▼ (若客户中间中断了对话...)
       │
[AI Agent 触发自动化定时器]
├── 离线 2 小时后：AI 主动发送预估月供试算表 ("Te preparé este cálculo preliminar...")
└── 离线 18 小时后：AI 主动提醒 ("Mañana aumentan los precios de promoción, ¿te ayudo a verificar tu Buró?")
```

### 三、 主动发消息的技术实现方式

触发 Agent 主动发消息的方式主要有：

1. **工作流/定时器触发（Workflow Scheduler）**：

2. 在 ManyChat、Dify 或 Make\.com 中设定节点：若对话状态为 `Waiting_Customer_Reply` 且时间过去 X 小时，Agent 调用 API 发送指定跟进话术。

1. **外部事件/CRM 触发（Webhook / Event\-Driven）**：

2. 当CRM 系统里客户状态发生变更（例如：线索状态变为“待跟进”），CRM 通过 Webhook 告诉 AI Agent：“现在主动给这个客户发送车贷初审通过的通知”。

### 四、 避坑指南（防止被封号）

1. **必须获得客户授权（Opt\-in）**：在 Facebook 广告、网页表单上，需有明确勾选框（如“同意通过 WhatsApp 接收车贷方案”），防止客户举报垃圾信息。

1. **模版消息分类正确**：将主动发送的唤醒模版正确归类为 Marketing（营销）或 Utility（服务通知），且需控制发送频率，避免触发 Meta 的高退订率/封禁机制。
