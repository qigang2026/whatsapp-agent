## 核心状态机

```
新线索 → 首次触达 → 建立有效对话 → 确认需求 → 车型/方案引导 →
金融意向确认 → MStar 转接/预审 → 资料推进 → 审核 → 成交/暂缓/关闭/再激活
```

**结束态只有 4 种**：成交 / 暂缓 / 关闭 / 再激活

## 跟进节奏（D+1 → D+7）

| 时机 | 动作 | 原则 |
|---|---|---|
| T0 新线索 | 5–15 分钟首触 | 不重复催促 |
| D+1 无回复 | 轻提醒，不重复介绍 | 礼貌激活 |
| D+3 无回复 | 换价值点（车型/金融/预审）| 不重复催促同一份资料 |
| D+7 无回复 | 礼貌收口，停止高频跟进 | 保留再激活入口 |

## 关键原则（检查清单）

- ❌ 不重复催促同一份资料
- ❌ 不承诺"一定获批/固定利率/零首付"
- ❌ 不机械重复已说过的内容
- ✅ 每次沟通必须产生"下一动作 + 负责人 + 时间"
- ✅ 关闭客户必须**记录原因 + 保留再激活入口**

## 边界情况处理

| 场景 | 处理 |
|---|---|
| 客户只回 "gracias/ok" | 视为有效对话，继续推进 |
| 已读 24h 不回 | 等到 D+3 再发 HSM |
| 客户明确拒绝 | 标记关闭，记录原因，保留再激活入口 |
| 禁联系名单客户 | 系统级拦截，禁止任何触达 |
