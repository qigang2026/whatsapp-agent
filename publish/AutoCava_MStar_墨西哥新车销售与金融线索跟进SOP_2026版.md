# **1\. 销售流程总览与角色边界**

**标准流程：线索进入 → 首次触达 → 建立有效对话 → 确认新车需求与预算 → 车型/方案引导 → 金融意向确认 → MStar 转接/预审 → 资料与审核推进 → 金融/经销商协同 → 成交 / 暂缓 / 关闭 / 再激活。**

|**阶段**|**销售关键动作**|**完成标准**|
|---|---|---|
|新线索|读取来源、车型页、已知信息；5–15 分钟内首触|已发出有效首条消息，送达状态已确认|
|有效对话|确认新车需求、车型方向、城市、首付/月供、购车时间|信息足够判断下一步|
|方案引导|先回答客户当前问题，再围绕车型/预算缩小选择|客户明确希望继续了解的方向|
|金融意向|解释基础方案与实际评估的区别；确认是否愿意预审或接受 MStar 联系|客户明确同意或明确暂不继续|
|MStar 转接|携带完整上下文转交并跟踪真实接通|MStar 已联系/已接通或有明确反馈|
|资料/审核|处理链接、资料、Buró、收入证明、补件、等待结果等卡点|每次都形成下一动作和时间|
|正式推进|可继续后确认车型、首付、期限、资料和经销商协同|进入正式申请/报价/签约/交付节点|
|结束/培育|记录成交、暂缓、未通过或长期无回复原因|当前任务关闭且保留历史上下文|

# **2\. 线索进入、首次触达与需求确认**

## **2\.1 线索进入前先读取已有信息**

销售发送第一条消息前，应先读取网站来源、广告来源、车型/品牌页、历史消息、CRM 备注、已有预算与城市信息。客户已经给过的信息不再重复询问。

|**进入时必须检查**|**示例**|
|---|---|
|来源与页面|AutoCava 首页 / 某车型页 / 金融页 / 广告 / WhatsApp|
|车辆信息|Kia K3、MG sedan、SUV、尚未确定车型|
|资金信息|首付 100,000 MXN、目标月供 ≤ 10,000 MXN、仅问最低首付|
|地理信息|CDMX / Mérida / 其他城市|
|历史金融信息|曾被银行拒绝、担心 Buró、自由职业、无法提供 nómina|
|沟通偏好|只接受 WhatsApp、下午联系、指定某天回访|



## **2\.2 首次触达 SLA**

|**场景**|**时效**|**动作**|
|---|---|---|
|正常新线索|5–15 分钟|完成首次 WhatsApp；高峰期尽量不超过 30 分钟|
|消息 Failed / 未送达|发现后尽快处理|检查号码/模板/渠道状态，重试或转人工；不得计为客户无回复|
|客户已指定联系时间|按客户指定时间|客户指定时间优先于默认跟进节奏|



## **2\.3 首次有效对话要逐步确认的信息**

|**信息**|**优先确认方式**|
|---|---|
|新车需求|确认是否接受新车；只要 seminuevo/usado 的客户明确说明范围|
|车型方向|具体车型 \> 品牌 \> 车身类型 \> 用途；不要一次给大量车型|
|城市|用于判断后续经销商与交付协同|
|首付/预算|优先问客户可准备的实际范围，而不是逼问“最低多少”|
|月供目标|客户主动给出时记录，用于反推车型/首付/期限组合|
|购车时间|近期 / 1–3 个月 / 暂时比较；决定跟进频率|
|收入方式|进入金融评估后再问：nómina / independiente / estados de cuenta 等|
|历史申请|客户主动提及银行拒贷、Buró 或其他问题时记录，不做负面标签|



|**对话动作**<br>客户先问价格、月供、利率或最低首付时，先承接并回答其问题，再补问推进所需信息。不要用“先填表/先预审”回避客户当前问题。|
|---|



# **3\. 车型、预算与金融方案引导**

## **3\.1 车型已明确**

围绕客户已选车型继续，不重复问车型。补齐版本、城市、首付、月供目标和购车时间；如需要正式金融条件，再引导进一步评估。

## **3\.2 车型未明确**

用“车身类型 \+ 用途 \+ 预算 \+ 首付/月供”缩小到 2–3 个方向。目标是帮助客户做选择，不是一次发送大量品牌与车型。

## **3\.3 网站金融方案的使用方式**

AutoCava 页面中的金融方案用于给客户建立基础认知，可以作为参考展示；实际首付、月供、期限、利率和可行性需结合客户资料及当前金融政策评估。客户看完基础方案后，可自然引导 MStar 做更个性化的预审。

|**客户问题**|**销售处理**|
|---|---|
|“月供多少？”|说明受车型、首付、期限、利率与评估结果影响；可先给参考，但标注为参考|
|“最低首付多少？”|说明需结合车型与方案；询问客户实际可准备首付|
|“能不能零首付？”|不承诺。说明取决于客户资料、车型和当前可用方案|
|“利率多少？”|不先承诺固定利率；进入实际评估后由 MStar 结合资料说明|
|“能不能保证通过？”|明确无法提前保证；预审就是为了判断可行性和下一路径|



# **4\. AutoCava → MStar 金融转接 SOP**

## **4\.1 什么时候转 MStar**

|**触发场景**|**处理**|
|---|---|
|客户明确愿意做预审/金融评估|当次取得同意并转 MStar|
|客户看完 AutoCava 基础金融方案，想看更实际条件|解释基础参考与个性化评估区别后转 MStar|
|银行曾拒绝 / Buró 有顾虑 / 收入形式灵活|不要自行判断审批概率，转 MStar 评估|
|客户直接问特殊利率、复杂资料、具体通过可能性|由 MStar 顾问判断|
|AutoCava 预审链接暂不可用/更新中|不让客户停滞，征得同意后直接转 MStar|



## **4\.2 对客户如何介绍 MStar**

MStar 是与 AutoCava 协同的专业汽车金融团队，可根据客户的实际资料做更个性化的汽车金融评估。相比只看网页上的基础参考，MStar 顾问会结合车型、首付、期限、收入与信用情况确认实际可行方向。预审可用“sin costo y sin compromiso”表达，但最终审批、利率、费用、首付要求均以实际审核为准。

## **4\.3 转接前必须形成客户摘要**

|**字段**|**必须包含的信息**|
|---|---|
|客户|姓名、电话、语言偏好|
|购车|车型/品牌/车身类型、城市、购车时间|
|预算|首付、月供目标或整体预算|
|金融情况|是否曾银行拒绝、收入方式、客户主动提到的 Buró/资料问题|
|当前状态|看过方案 / 已同意预审 / 已提交部分资料 / 等顾问联系|
|方便联系|客户指定日期、时间、WhatsApp/电话偏好|
|待解决问题|客户最关心的一个问题，例如通过率、首付、资料、月供|



## **4\.4 转接完成标准**

“已转给 MStar / 已分配顾问”不等于完成。销售要继续跟踪到顾问已接受、已联系、最好确认已与客户建立有效沟通；若客户反馈“没有人联系”，必须重新核实号码、方便联系时间及 MStar 状态。

|**内部转接模板**<br>Hola Raúl, te comparto un cliente de AutoCava para apoyo con la evaluación financiera\.<br>Cliente: \[Nombre\] \| Tel: \[Número\] \| Ciudad: \[Ciudad\]<br>Vehículo: \[Modelo / preferencia\] \| Enganche: \[Monto\] \| Mensualidad objetivo: \[Monto\]<br>Situación: \[interés / banco rechazó / independiente / Buró / etc\.\]<br>Horario preferido: \[Hora\]<br>Ya confirmó que está de acuerdo con ser contactado por MStar\. Gracias por el apoyo\.|

# **5\. 预审、资料、补件与审核结果推进**

## **5\.1 预审推进标准动作**

|**节点**|**销售动作**|**下一步**|
|---|---|---|
|客户同意预审|说明作用，发送当前有效入口或转 MStar|记录发送/转接时间|
|发送后 2–4 小时无进展|轻提醒，先问是否没时间或遇到问题|识别具体卡点|
|1 天仍未完成|按隐私、Buró、月供、首付、收入证明、操作、时间分类处理|约定明确行动/时间|
|填写中断|只问停在哪一步/缺什么，不让客户重做已完成内容|继续填写或补资料|
|资料已提交|确认收到，不重复索取；等待金融团队反馈|生成结果回访任务|



## **5\.2 常见资料**

以下仅作为常见示例，具体清单由 MStar 根据客户情况确认：

|**资料类型**|**示例**|
|---|---|
|身份证明|INE 正反面或金融团队认可的有效身份证明|
|地址证明|Comprobante de domicilio|
|联系方式|Correo electrónico、有效联系电话|
|收入证明|近 3 个月 estados de cuenta、recibos de nómina，或其他被接受的收入材料|
|其他|按客户资料、金融机构和审核状态追加|



|**资料跟进**<br>客户已经提交 INE 时，后续只提醒尚缺的地址证明/流水等，不重复让客户再次发送 INE。涉及身份证明、银行流水等敏感资料时，进入受控的金融/人工流程。|
|---|



## **5\.3 审核结果后的动作**

|**结果**|**当天动作**|
|---|---|
|可继续 / 预审通过|确认车型、版本、首付、期限、缺失资料、所在城市；进入正式方案/经销商协同|
|需要补件|明确缺失项、格式/提交方式、负责人和预计反馈节点|
|当前方案未通过|如实说明；根据实际原因看是否可调整车型、首付、期限或其他路径|
|暂无替代方案|清晰结束，不制造“肯定还能过”的希望；记录再评估条件|
|等待时间较长|向 MStar 核实真实状态；不编造结果时间|



## **5\.4 经销商交接与交付**

金融方向明确后，再对接经销商确认具体车型、版本、库存、正式报价、签约和交付。AutoCava 可协助协调当地/附近经销商，但在经销商确认前不承诺某门店一定有现车、固定优惠或即时交付。

# **6\. 主动跟进节奏与客户优先级**

## **6\.1 默认跟进时间表**

|**时间/触发**|**客户状态**|**动作**|
|---|---|---|
|T0|新线索|5–15 分钟首触|
|D\+1|首触 24 小时无回复|轻量确认是否仍在考虑；不重复长介绍|
|D\+3|连续无回复|更换价值点：车型建议 / 金融可行性 / 预审|
|D\+7|多次无回复|礼貌收口，停止高频跟进，保留再激活入口|
|2–4 小时|已发预审/资料入口无进展|询问是否遇到问题或是否需要改时间|
|当日|收到补件/审核结果|当天反馈并明确下一步|
|客户指定时间|客户明确 later / mañana / viernes / 某时|按客户指定时间回访，覆盖默认节奏|



## **6\.2 处理优先级**

|**优先级**|**客户状态**|**跟进要求**|
|---|---|---|
|最高|已提交、已通过、补件、正式申请/报价/签约中|当天重点跟进，确保不因内部等待丢失|
|高|明确购车意向、已同意 MStar、已打开/填写预审|当日推进；必要时 2–4 小时提醒|
|中|有新车需求、车型/预算较明确、仍在比较|1–2 天内推进到明确下一步|
|低/培育|购车时间较远、首付尚未准备、条件待改善|3–7 天或按客户时间轻触达|
|关闭|明确拒绝、只要二手车、多次无回复、当前无可行路径|停止高频联系；保留历史和再激活时间|



# **7\. CRM 状态、记录与任务关闭**

## **7\.1 建议状态**

|**状态**|**定义**|
|---|---|
|新线索|刚进入，尚未首触|
|已触达|已发送有效消息，等待回复|
|已回复|客户已形成有效对话|
|需求明确|已确认新车需求、车型/方向、城市和预算信息|
|金融意向|客户愿意预审或了解更实际金融方案|
|已转 MStar|已取得同意并转接，正在确认是否接通|
|资料/预审中|链接已发、填写中、资料补充中|
|审核中|资料已提交，等待金融结果|
|可继续|预审/金融反馈可推进|
|正式推进|经销商/正式申请/报价/签约/交付中|
|成交|完成购买|
|暂缓/培育|客户暂时无法继续，但未来可能恢复|
|关闭|明确不匹配/拒绝/长期无回复且本轮结束|



## **7\.2 每次沟通后必须更新**

|**字段**|**内容**|
|---|---|
|客户需求|车型/方向、城市、购车时间|
|支付条件|首付、月供目标/预算|
|当前问题|例如 Buró、收入证明、最低首付、等待 MStar 联系|
|已完成动作|已发方案 / 已转 MStar / 已收 INE / 已补地址证明|
|下一动作|动作 \+ 负责人 \+ 时间，例如“明天 15:00 回访”|
|负责人|AutoCava / MStar / 经销商 / 运营|
|异常/偏好|Failed、号码异常、只接受 WhatsApp、指定时间等|



## **7\.3 任务关闭标准**

只有当 CRM 中写清“本次结果 \+ 下一动作/关闭原因”后，任务才算完成。客户回复但未记录、已转 MStar 但不知道谁接收、链接已发但没有发送时间、补件后没有下一反馈节点，都属于未闭环。

# **8\. 异常场景与跨团队协同**

|**异常**|**处理方式**|
|---|---|
|WhatsApp Failed / 未送达|与“客户不回复”区分；检查号码格式、模板、渠道状态并重试，必要时运营介入|
|多个号码/多条会话|保留主会话和明确负责人，避免多人重复询问同一客户|
|Bot/团队重复提问|先查看完整上下文，已提供的信息不得再次索取|
|AutoCava 预审链接更新/不可用|对客户用“en proceso de actualización”表达；取得同意后直接转 MStar，避免停滞|
|MStar 已分配但客户未接通|向 MStar 查 accepted/contacted 状态，同时确认客户方便时间和号码|
|MStar 顾问迟迟无反馈|AutoCava 主动催状态并向客户说明正在核实，不让客户在两个团队之间找人|
|复杂 Buró / 特殊审批概率|不由 AutoCava 销售口头判断，交由 MStar|
|客户投诉/强烈隐私顾虑|停止自动式催促，人工接管并先核对已提供信息|
