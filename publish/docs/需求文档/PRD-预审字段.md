# AutoCava 金融预审订单 · 字段清单

> 用途：autocava 平台金融预审订单需收集的字段说明  
> 更新说明：购车用途、所属渠道由系统自动补充；出生日期由 RFC（税号）推算

---

## 字段总览

| 模块 | 字段 | 必填 | 填写方式 | 说明 |
|------|------|------|----------|------|
| 财务信息 | RFC（税号） | ✅ | 用户填写 | 墨西哥税号 |
| 财务信息 | 月收入 | ✅ | 用户填写 | — |
| 基础信息 | 姓名（全名） | ✅ | 用户填写 | 四段：名字 / 中间名 / 父姓 / 母姓 |
| 基础信息 | 出生日期 | ✅ | **系统推算** | 根据 RFC 自动计算，无需用户手填 |
| 基础信息 | 性别 | ✅ | 用户填写 | — |
| 基础信息 | 电话 | ✅ | 用户填写 | 接受征信授权链接的手机号；联系客户用；使用注册手机号 |
| 基础信息 | 邮箱 | ✅ | 用户填写 | 接受征信授权链接的邮箱 |
| 地址信息 | 国家 + 州 + 市/区 + 区 + 街道 + 门牌号 + 内门牌号 | ✅ | 用户填写 | 户籍地址或居住地址均可；国家/州/市（或区）/区可根据邮编反推 |
| 地址信息 | 邮政编码（C.P.） | ✅ | 用户填写 | 5 位纯数字 |
| 其他 | 购车用途 | ✅ | **系统自动补充** | 默认「个人用车」；可选：个人用车 / 滴滴&Uber / 经营用车 |
| 其他 | 所属渠道 | ✅ | **系统自动补充** | 订单归属渠道；默认 AutoCava |

---

## 分模块说明

### 1. 财务信息

| 字段 | 必填 | 填写方式 | 说明 |
|------|------|----------|------|
| RFC | ✅ | 用户填写 | 税号 |
| 月收入 | ✅ | 用户填写 | — |

### 2. 基础信息

| 字段 | 必填 | 填写方式 | 说明 |
|------|------|----------|------|
| 姓名（全名） | ✅ | 用户填写 | 有四部分：名字、中间名、父姓、母姓 |
| 出生日期 | ✅ | **系统推算** | 根据 RFC（税号）自动计算 |
| 性别 | ✅ | 用户填写 | — |
| 电话 | ✅ | 用户填写 | 接受征信授权链接的手机号；联系客户用；使用注册手机号 |
| 邮箱 | ✅ | 用户填写 | 接受征信授权链接的邮箱 |

### 3. 地址信息

| 字段 | 必填 | 填写方式 | 说明 |
|------|------|----------|------|
| 完整地址 | ✅ | 用户填写 | 国家 + 州 + 市/或区 + 区 + 街道 + 门牌号 + 内门牌号；户籍或居住地址均可；国家/州/市（或区）/区可根据邮编反推 |
| 邮政编码（C.P.） | ✅ | 用户填写 | 5 位纯数字 |

### 4. 其他（系统自动）

| 字段 | 必填 | 填写方式 | 说明 |
|------|------|----------|------|
| 购车用途 | ✅ | **系统自动补充** | 默认「个人用车」；枚举：个人用车 / 滴滴&Uber / 经营用车 |
| 所属渠道 | ✅ | **系统自动补充** | 订单归属于哪个渠道；默认 AutoCava |

---

## 填写方式归类（产品/研发对照）

| 类型 | 字段 | 产品含义 |
|------|------|----------|
| 用户必填 | RFC、月收入、姓名、性别、电话、邮箱、地址、邮编 | 预审表单需向用户收集 |
| 系统推算 | 出生日期 | 由 RFC 解析，表单可不展示手填项（建议只读回显） |
| 系统自动补充 | 购车用途、所属渠道 | 无需用户填写；带默认值，可按业务规则覆盖 |

---

## 备注

- 电话与邮箱同时用于**征信授权链接下发**与**客户联系**
- 地址：完整层级为「国家 → 州 → 市/或区 → 区 → 街道 → 门牌号 → 内门牌号」；前半段可依邮编反推
- 购车用途、所属渠道虽为必填字段，但由系统写入，不计入用户侧采集负担
