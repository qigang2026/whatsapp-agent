## 1. 现状 vs 目标

### 1.1 当前工作台结构

```
工作台（44c20c9f）
  ├─ Hero + 时间筛选
  ├─ KPI 4 卡（待销售接管 18 / SLA 4分12秒 / AI接管 47 / 销售接管 32 / 已超时 6）
  ├─ 线索生命周期分布（条形图）
  ├─ 趋势分析 · 近 7 天（折线图）
  ├─ 转化漏斗
  ├─ SLA 达标率
  ├─ 车型热度 Top 5
  ├─ 今日异常会话表（3 行）
  ├─ 工作台主路径 · 一句话产品规则
  └─ 待 PM 拍板
```

**问题**：
1. 4 个图表占主区，但销售**用不上**（老板/运营才看趋势 + 漏斗 + SLA + 车型热度）
2. 没有"今日任务"概念——销售登录后不知道**先做什么**
3. 异常会话只有 3 条但不告诉销售**怎么操作**
4. 缺少优先级排序和 Agent 主动建议

### 1.2 目标工作台结构（参考万联有客）

```
工作台 v2 · 销售视角

  │
  ├─ 📊 运营视角（折叠区 · 原 4 图表保留）

  │   ├─ SLA 达标率
  │   └─ 车型热度 Top 5
  │
  ├─ 异常会话 · 需立即处理（折叠区 · 原 3 行表）
  ├─ 产品规则（保留）
  └─ 待 PM 拍板（保留）
```

## 2. 今日任务模块详细设计

### 2.1 销售工作漏斗概览（4 个 KPI · 精简版）

参考万联有客 4 卡结构：线索 → 注册 → 认证 → 发货

| KPI | 当前值 | 趋势 | 说明 |
|-----|--------|------|------|
| 今日新增线索 | 18 | ↑ 3 较昨日 | 待分配 / 待首次接洽 |
| AI 接管中 | 47 | ↑ 8 较昨日 | 自动跟进，无需干预 |
| 待销售接管 | 10 | - 较昨日 | 需在 SLA 工时内响应 |
| 已超时 | 6 | ↑ 2 较昨日 | 超过 1h 未响应 · 立即处理 |

**对比现状**：现在 4 卡是「待销售接管 / SLA 剩时 / AI接管 / 销售接管 / 已超时」5 项，参考万联有客改成 4 项漏斗形态：
- **今日新增线索**（线索入口）
- **AI 接管中**（AI 在跟）
- **待销售接管**（销售要接）
- **已超时**（销售漏接）

**优势**：每个数字 = 一个动作（漏接 / 待接 / AI 跟 / 新增），销售一眼就懂

### 2.2 今日任务表格明细
